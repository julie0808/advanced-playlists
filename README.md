# Liste de lecture Youtube avancées

Étant une utilisatrice avide de Youtube, j'ai atteint un point où mes listes de lectures sont devenues inutilisables. Spécialement pour les listes de musique avec plus de 1000 items, il est difficile de trouver la musique que je veux écouter.

## La solution

Créer un système de "tags" pouvant être associés aux videos de mes listes d'origine sur Youtube. Dans cette application, à l'aide de filtres, je peux donc tailler une liste de lecture reflétant ce que je veux écouter au moment importun.

### Fonctionnaliés clés

- Gérer des "tags"
- Gérer les tags associés aux vidéos provenant de playlists sur Youtube
- Lecture à même l'application, selon les filtres choisis
- Branchement à l'authentification Youtube pour que l'app prenne en compte l'abonnement Youtube Premium

## Utilisation de l'outil

Il est uniquement possible d'utiliser l'outil en environnement local. Voir la [documentation technique](_doctech/tech.md). L'application n'a pas de plan d'être hébergée sur le Web étant donné sa nature rudimentaire.


## Choix technologiques

- Angular
- Node.js pour le Backend
